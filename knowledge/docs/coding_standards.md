# 企业编码规范文档

## 1. Python编码规范

### 1.1 命名规范
- **模块名**: 全部小写，使用下划线分隔，如 `user_service.py`
- **类名**: 采用大驼峰命名法，如 `UserService`
- **函数/方法名**: 全部小写，使用下划线分隔，如 `get_user_info()`
- **变量名**: 全部小写，使用下划线分隔，如 `user_name`
- **常量名**: 全部大写，使用下划线分隔，如 `MAX_RETRY_COUNT`

### 1.2 代码风格
- 使用4个空格进行缩进，禁止使用Tab
- 每行代码最大长度不超过120字符
- 二元运算符前后需要加空格
- 逗号后面需要加空格

### 1.3 注释规范
- 模块开头必须有文档字符串，说明模块功能
- 类和函数必须有文档字符串
- 复杂逻辑需要添加注释说明

### 1.4 导入规范
- 导入按以下顺序排列：
  1. 标准库导入
  2. 第三方库导入
  3. 项目内部导入
- 禁止使用 `from module import *`

### 1.5 异常处理
- 禁止捕获所有异常（`except Exception`）
- 只捕获明确需要处理的异常类型
- 异常信息需要包含足够的上下文

## 2. 错误处理规范

### 2.1 返回状态码
- 200: 成功
- 400: 请求参数错误
- 401: 未授权
- 403: 禁止访问
- 404: 资源不存在
- 500: 服务器内部错误

### 2.2 日志记录
- 所有对外API必须记录请求和响应日志
- 异常发生时必须记录错误日志
- 日志级别：DEBUG、INFO、WARNING、ERROR、CRITICAL

## 3. 数据库规范

### 3.1 SQL编写
- 禁止拼接SQL，必须使用参数化查询
- 复杂查询使用ORM框架
- 大表查询必须添加索引

### 3.2 事务管理
- 多表操作必须使用事务
- 事务边界要明确
