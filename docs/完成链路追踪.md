项目 DevEnterpriseAI 基础架构已搭建完成。

## 项目目录结构
```
/home/zt/DevEnterpriseAI/
├── __init__.py              # 项目主入口
├── config/                  # 全局配置模块
│   ├── __init__.py
│   └── settings.py          # 配置管理（LLM、向量库、内存、日志等）
├── core/                    # 核心内核模块
│   ├── __init__.py
│   └── llm.py               # LLM接口封装（支持OpenAI兼容接口）
├── tools/                   # 自定义工具模块
│   ├── __init__.py
│   └── base.py              # 工具基类（注册机制、工厂模式）
├── knowledge/               # 知识库模块
│   ├── __init__.py
│   ├── ingest.py            # 文档入库脚本（支持txt/pdf/docx/md）
│   └── vectorstore/         # 向量库持久化目录
├── utils/                   # 通用工具模块
│   ├── __init__.py
│   ├── logger.py            # 日志工具（轮转日志）
│   └── exception.py         # 异常体系定义
├── logs/                    # 日志输出目录
├── .env                     # 环境变量配置（密钥管理）
├── .env.example             # 环境变量模板
└── requirements.txt         # Python依赖
```
## 核心特性
模块 功能 config 基于Pydantic的强类型配置，.env文件管理，支持模型API密钥、地址、温度、向量库路径等 core EnterpriseLLM 统一封装OpenAI兼容接口，支持私有化大模型； EmbeddingsClient 向量化客户端 tools BaseTool 抽象基类 + ToolFactory 工厂模式，支持工具注册和动态加载 knowledge DocumentLoader 多格式文档加载 + KnowledgeIngestor 分块向量化存储 + Chroma持久化 utils 企业级日志（轮转）+ 层次化异常体系

## 快速开始
1. 复制配置模板并填写实际值：
```
cp .env.example .env
```
2. 安装依赖：
```
pip install -r requirements.txt
```
3. 在 .env 中配置您的私有化LLM地址和API密钥，即可使用框架提供的所有功能。
